# Project AI Bootstrap

The official installer for Project AI Cloud on Termux.

## Installation

Install curl:

    pkg install curl -y

Download the installer:

    curl -fL https://raw.githubusercontent.com/uugoibemere-bit/ProjectAI-Bootstrap/main/projectai-bootstrap -o projectai-bootstrap

Run it:

    bash projectai-bootstrap

A GitHub account with collaborator access to ProjectAI-Repo is required.
